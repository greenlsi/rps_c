# RPS C Raft Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `build/rps_node`, a real TCP Raft rock-paper-scissors node in C.

**Architecture:** Implement the deterministic RPS FSM, encode all user actions as `rps.*` Raft commands, apply only committed operations through `raft_application_t`, and run the CLI as an rxnet FSM in the same cooperative runtime as Raft.

**Tech Stack:** C99, `raft_rx` C, `rxnet` C, Make, small C test harnesses.
